- Textures: shared trims and tiling sets <= 2048^2 (albedo sRGB, normal OpenGL, ORM); hero landmarks one unique 2k set each; LOD2 atlases <= 512^2; everything baked out of Blender; a per-asset window emissive mask for lit windows at dusk later.
- Glass: tinted, lightly reflective, with fake interiors (interior mapping or painted interior cards); never black holes or mirrors.
- Web: the game renders with three.js r169 MeshStandardMaterial, ACES Filmic, golden sun + HDRI env, cascaded shadows. No reliance on SSS, refraction or procedural nodes; albedo between 0.03 and 0.85 linear.
- Reproducible: `blender -b --python tools/blender/build_building_kit.py -- --out assets/buildings/building_kit.blend` rebuilds the whole kit from scripts, marks everything as Blender Assets in catalogs by district and class, and renders previews.
- Exports: exports/buildings/glb/<asset>.glb (LODs as nodes); tools/blender/export_web_buildings.py (modelled on export_web_trees.py) -> app/world/buildings/geo.bin + geo.json + textures; data/buildings/kit_catalog.json per asset: id, district, class (building_types.json key), replace_with, style, era_decade, footprint_m, height_m, storeys, roof, lod_tris, materials, colour presets, wear range, zone tags (downtown, town_center, town, rural, farm, industrial, highway, riverfront, rail), suitable settlements/landmarks, frontage road types (road_types.json), description.

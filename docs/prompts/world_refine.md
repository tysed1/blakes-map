# 4. PERFORMANCE PLAYBOOK (Agent R leads; N and E apply it in their modules; ranked by expected gain; measure each)
1. Static sun => bake it. Bake a world-space sun shadow + ambient-occlusion map for terrain, canopy and large structures once (Blender bake or a one-off GPU pass at build time, e.g. 4096 x 1366 over the map + a coarse one for the backdrop), and sample it in the terrain/ground/road shaders. Keep real-time CSM only for the near field (High: 2 cascades to ~300 m; Medium: 1 cascade; Low: none, baked only). Near-field casters: LOD0-1 trees, props, structures only.
2. Far forest as impostors: bake octahedral (or at least 8-view) impostors per species (albedo + normal + depth atlas) and replace LOD3/LOD4 with instanced impostor quads; far canopy density matches the Blender renders at a fraction of the cost. Dithered cross-fade between LODs.
3. Draw calls: merge static far geometry per cell (infra, rocks, far trees) or use BatchedMesh where WEBGL_multi_draw is available (fallback path for Safari); one material per family via texture atlases/arrays; target the budgets below.
4. Textures: KTX2 (Basis UASTC for normals/detail, ETC1S for albedo) via KTX2Loader with its wasm transcoder (ASTC on Apple GPUs); mipmaps everywhere; stop shipping 6000 px JPEGs uncompressed to VRAM; atlas the card and detail textures. Keep a fallback for the artifact host (it serves .wasm, .js, .json, .png, .jpg, .webp, .txt; .ktx2/.bin files are packed like the existing .bin -> .gz.b64.txt path, so extend prepare_artifact.py and the loader accordingly).
5. Geometry: meshopt-compressed, quantized buffers for trees, infra and ground cover; decode in a Web Worker; stream by distance (near cells first) so the world is interactive in < 5 s and refines after.
6. Terrain: one clipmap/CDLOD mesh with height from a texture in the vertex shader, geomorphing between levels (no pops, a handful of draw calls), normals from a normal map; skirts gone.
7. Foliage shading on a tile-based GPU (Apple TBDR): alpha-tested overdraw is the killer. Use opaque cores + alpha cards only near, opaque card clusters at mid range, impostors far; alpha-to-coverage only where MSAA is on; keep fragment shaders short (no per-pixel noise loops); early-out for fully faded instances.
8. Post: one fused uber-pass (shafts + grade + vignette + sharpen), bloom at quarter resolution, no extra full-screen HalfFloat passes; MSAA is cheap on TBDR but render-target switches and full-screen reads are not.
9. CPU: zero per-frame allocations (reuse vectors/matrices), cull and LOD in throttled batches (or a worker), no GC spikes, cheap picking (only on click).
10. Grass: radius and density per preset, blade LOD, never draw under props/roads, fade into the baked albedo seamlessly.
11. Download: target < 40 MB total (from ~73 MB) and first interactive frame < 5 s on a 50 Mbit/s connection; stream the rest.
12. Adaptive quality: keep the resolution governor; add an LOD-bias governor; presets Low / Medium / High / Ultra with sane defaults; auto-pick the preset on first run from a 2-second benchmark.
13. Compatibility: WebGL2 on Chrome, Safari and Firefox on macOS; no features without fallbacks; the local package and the artifact deploy both work.
